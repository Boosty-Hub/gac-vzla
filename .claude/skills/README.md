# Skills del Proyecto GAC Venezuela

Skills especializadas para trabajar eficientemente en este proyecto con Claude Code.

## Skills disponibles

| Skill | Cuándo usar |
|---|---|
| `supabase-gac` | Operaciones de DB, migraciones, RLS, edge functions, queries SQL |
| `kommo-gac` | Integración Kommo CRM: leads, pipelines, webhooks, sync |
| `frontend-gac` | Páginas React, componentes, formularios, rutas, permisos en UI |
| `context-manager` | Sesiones largas, /compact, memorias, mejora de prompts |
| `requirements-gac` | Implementar requerimientos, workflow, checklist, priorización |

## Cómo usar

Las skills se activan automáticamente cuando Claude detecta el contexto adecuado.
También puedes invocarlas manualmente con `/skill-name`.

## Actualizar una skill

Editar el `SKILL.md` correspondiente en su carpeta.
Estas skills son específicas del proyecto y viven en `.claude/skills/`.
